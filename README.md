# 🎵 Concerts & Events Management System

## 📌 Project Overview
The Concerts & Events Management System is a database project developed using SQL. It is designed to manage concert information, event details, ticket bookings, and customer records.

## 🎯 Project Objectives
- Manage concert and event information.
- Store customer details.
- Maintain ticket booking records.
- Retrieve information using SQL queries.
- Understand database relationships and constraints.

## 🛠️ Technologies Used
- SQL
- SQLite
- DB Browser for SQLite

## 📚 SQL Concepts Covered
- CREATE and INSERT
- UPDATE and DELETE
- PRIMARY KEY and FOREIGN KEY
- SQL Constraints
- Joins
- Subqueries
- UNION and UNION ALL
- CASE statements
- Aggregate Functions

Academic / Learning Project
